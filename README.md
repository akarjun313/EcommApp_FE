# ⌚ WristWatch - E-Commerce Frontend  

**Live Demo:** [Vercel Link](https://ecomm-app-fe.vercel.app/)

## 📌 Overview  
A React-based e-commerce platform for wristwatches with:  
- **Role-based dashboards** (User, Seller, Admin)  
- **Razorpay payment integration**  
- **Responsive UI** (TailwindCSS + DaisyUI)  

## 🛠 Tech Stack  
- **Framework:** Vite + React  
- **Styling:** TailwindCSS + DaisyUI  
- **State Management:** Recoil  
- **Payment Gateway:** Razorpay  

## 🔗 Backend Connection  
This frontend connects to this repo: [WristWatch Backend Repo](https://github.com/akarjun313/EcommApp_BE.git)
**Base API URL:** `https://ecommapp-be.onrender.com`
